Overview

IIMB DBE Entrance Test is run by IIM Bangalore for admission to BBA programmes. 1 college accepts it: IIM Bangalore – BBA DBE (online).

Online degree, not a residential campus programme. CUET or JEE Main scores can be used instead of IIMB's own test.
